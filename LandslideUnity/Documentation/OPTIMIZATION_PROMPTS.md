## P0｜合并总提示词（一次投喂版）

```text
你是地质地貌可视化导演兼教学动画导演。请对一段 24 秒、1280×720、30 fps 的「降雨诱发山体滑坡」教学演示视频做画面与叙事改造。目标不是增加特效，而是让观众在滑坡真正发生前无法预知哪里会滑，让地形成为决定运动路径的主角，让滑动呈现多阶段、多方向、非匀速的真实过程。

【当前画面的三个问题】
1. 剧透：第 0 秒草坡上就有一块边界锐利、颜色饱和的黄褐色椭圆斑，形状位置明确标出未来滑体；到第 2 秒（降雨入渗 51 min）几乎无变化。观众一开始就知道了答案，失去「突然发生」的张力。
2. 地形单一：整个区域是一块平整斜面，只有几条平行规则的浅色条纹；没有主沟谷、支沟、山脊、阶地、凹陷、岩层出露或侧向转折，远山也只是整齐平行剪影，不像真实山区。
3. 运动简单：滑体沿同一条对角直线匀速下行，宽度均匀、边界平直，没有因地形偏转、分叉、汇流、扩散、停滞再启动；近景里是一整片光滑褐带，看不出块体、厚度、翻滚与叠压。

【改造目标】
A. 让「哪里会滑」在发生前完全不可预知，观众与片中村民一样是「突然发现」；
B. 让地形本身能解释「滑体为什么往那边走」；
C. 让运动表现为「静止—蠕动—突然加速—受阻滞速—二次推进—扇形停积」的过程，而不是一条带子的平移。

【硬性边界】
- 只改画面表现、镜头与字幕节奏；不改变任何既有数值结果、片尾参数、物理数值链与验证结论。
- 片长仍为 24 秒 / 720 帧 / 30 fps；保持中文单行字幕、六段旁白时间点、片尾结果卡与致谢结构。
- 不恢复密集数据看板，不新增信息面板，不延长片长。
- 不出现与真实滑坡常识相悖的效果（爆炸、火光、整体腾空飞行、凭空出现的土块）。
- 所有新出现的土体必须能追溯到地表开裂、剥落、铲蚀或翻卷，不能凭空显形。

【交付要求】
给出逐秒的可见变化清单、改造后的分镜描述，以及可逐帧核对的验收标准；每条视觉要求都要写明「做到什么算合格」和「什么算没做到」。不要输出代码实现方案。
```

## P1｜消除滑体剧透：让失稳是「被发现」而不是「被预告」

```text
任务：重做滑坡发生前 0–4 秒的信息揭示节奏。这是一段降雨诱发滑坡教学片的开头，当前版本在第一帧就把未来滑体画成了一块显眼的黄褐色斑，观众立刻知道哪里会滑。请让它变成一次真实的「突然发生」。

【0–3.5 秒：完整、无差别的山坡】
- 整片坡面必须是连续、完整、看起来都一样的植被覆盖。未来会发生滑动的区域，在颜色、明度、纹理、湿度、边界、植被密度上与普通坡面完全一致，不允许任何可辨识的差异、暗边、色斑或贴图接缝。
- 这 3.5 秒里「变化」要发生在整片坡面而不是某一块：雨势渐强、草色随累计雨量整体变暗变湿、低洼处出现薄积水与反光、坡脚渗水变浑浊、雾气轻微下沉、零星落叶与小碎石被雨打动。
- 可以给 2–3 处不同位置都安排轻微前兆（细小湿痕、一小段地面鼓起、一处草皮轻微错位、一棵树略倾斜），让观众无法判断哪一处会出事；最终只有其中一处发展成主滑体，其余保持为无害的小迹象。

【3.5–4.5 秒：由点到面地揭示】
- 第一个可见信号必须是微小且局部的：后缘先出现 2–3 条细的深色张拉裂缝，随后一小片草皮下沉、错开，裂缝下方才露出一点湿土。
- 露出过程要沿裂缝网络逐渐扩展、连通、加深，绝不能一整块椭圆同时变色或一次性变成完整滑体。
- 新露出的土体颜色应是深、湿、低饱和的暗褐，与阴雨草地接近；随着暴露时间推移才逐渐变干、变亮、转为土黄。禁止开局使用高饱和黄褐色。
- 失稳瞬间用一次极短的镜头轻震与细碎开裂声，让观众「听见并发现」，而不是靠字幕宣告。

【禁止】
- 任何在第一帧就能圈出滑体范围的颜色块、边界线、高亮、描边或箭头。
- 整块区域同时变色、瞬间显形、从地面凭空长出土体。
- 用字幕或旁白提前说明「这里将要滑动」。

【验收】
- 盲测：把第 0 秒和第 2 秒截图给三位没看过视频的人，问「哪里会滑」，三人都指不出来才算合格。
- 第 3.5 秒之前，画面中不应出现任何连续成片的裸露土色区域。
- 第 4 秒的裸露面积应明显小于最终滑体面积，且形状不规则、边缘羽状。
- 把 0 / 2 / 3.5 / 4 / 5 秒五帧并排，应能看出「无迹象 → 局部细裂缝 → 扩展连通 → 整体启动」的递进。
```

## P2｜地形复杂度：从「一块斜坡」变成「一个流域」

```text
任务：重做整片山体的地形形态。当前版本是一块从左上到右下的平整斜面，几条平行浅色条纹当作冲沟，完全不像真实山区。请把它设计成一个有沟谷、山脊、阶地与堆积区的完整流域，并且让地形能够解释后续滑动的路径选择。

【必须出现的地貌要素】
- 一条**弯曲**的主沟谷：从上游蜿蜒到坡脚，走向随高程改变（S 形或折线），有明显的沟底、沟坡与深度感；不是直线条纹，也不与等高线平行。
- 2–3 条支沟在不同高程汇入主沟，汇入处有扇形小堆积与明显的交角。
- 沟谷之间至少 2 道凸起的脊梁或鼻状山嘴，以及 1–2 处局部台地/平缓平台。
- 上游后缘一处圈椅状浅凹陷（真实滑坡源区常见形态），但它在失稳前必须看起来只是普通的地形起伏，不能有任何暗示性标记。
- 中部 1–2 道横向岩脊或陡坎，能明显改变下滑物质的流向。
- 坡脚一处开阔的堆积扇 / 旧堆积体，地势变缓、物质变细。
- 局部基岩出露的灰白或深灰色斑块、碎石坡、冲沟切口处的土层剖面。

【地表覆盖】
- 草地、灌丛、裸土、碎石、湿地按坡度、高程、沟谷位置自然混合；边界是不规则的、羽状的、破碎的，不能是圆形或椭圆形色块。
- 不同坡向要有明暗与植被疏密差异；沟底更湿更暗、植被更密；脊顶更干更亮、更稀疏。
- 加入微地形：不均匀起伏、小凹坑、雨蚀细沟、局部塌痕，避免大面积极其平滑的曲面。
- 用树、房屋、一条蜿蜒小径或田埂、沟渠提供真实尺度参照，让沟谷深度和坡面起伏可被感知。

【远景与氛围】
- 远山不要整齐平行的剪影：山脊高低错落、有山口与谷地开口，与前景之间有连续的大气透视，不能出现一条水平色带把两者分开。
- 阴雨天气下整体降饱和、偏冷，主光柔和，沟谷内更暗，与「暴雨」设定一致。

【禁止】
- 单一平面 + 平行条纹的「地毯式」坡面。
- 规则重复的噪声花纹、菱形/网格状周期纹理。
- 把地形变化全部压在颜色上而没有实际凹凸轮廓。

【验收】
- 俯视全景下能数出至少 2 条弯曲沟谷、1 道横向脊、1 处上游凹陷与 1 处坡脚堆积扇。
- 低角度侧视时，坡面轮廓线应是起伏的折线/曲线，而不是一条笔直斜线。
- 遮住滑体只看地形，观众应能大致指出「水会往哪里流、土会往哪里走」。
```

## P3｜运动轨迹与运动学：让滑体「被地形牵着走」

```text
任务：重做滑体从启动到停积的全过程运动表现。当前版本是一条宽度均匀、边界平直的褐色带沿对角直线匀速平移。请让它变成一个被地形不断改变方向、分股、阻滞、扩散的多阶段过程。

【分阶段运动脚本】
1. 启动（约 3.5–5 s）：后缘不是整体同时动，而是多级张裂、块体逐级下错；先是几乎察觉不到的缓慢蠕动，随后突然加速。要有明确的「静止 → 动起来」的临界瞬间。
2. 上部收束（约 5–8 s）：物质向主沟谷汇聚，滑体被沟谷约束而**变窄、变厚、加速**，两侧草坡被铲刮出羽状擦痕。
3. 遇脊分叉（约 8–11 s）：滑体撞上横向岩脊后分成 2 股绕行，一股走主沟、一股漫上侧脊；两股速度不同、形状不同，在下游重新汇流。其中一股要出现明显的短暂受阻、堆厚、几乎停住，再被后续物质推动重新前进。
4. 沟谷转向（约 11–15 s）：沿弯曲主沟谷发生至少一次肉眼可见的**折向**；外侧出现剪切错动、侧向漫溢与小股越脊溢出；内侧出现挤压脊和块体叠压。
5. 坡脚扩散（约 15–20 s）：进入开阔堆积扇后速度明显衰减，前缘呈指状 / 舌状多分叉并**扇形铺开**，宽度显著增大、厚度变薄，块石在前缘翻滚后停住，细粒物质流得更远。
6. 停积（约 20–21 s）：不同部位先后停下，表面留下不规则垄岗、凹坑与块石堆，不是平滑楔形。

【形态与质感随时间变化】
- 宽度、厚度、颜色、表面结构全程都要变化；前缘始终有物质翻卷、坍塌、扬尘与飞石；后缘持续暴露新的拉裂台阶与层理。
- 块体大小不一、旋转方向不一，有碰撞、倾覆、叠压、被推挤停住；不能是一个整体同步平移。
- 前缘轮廓必须是不规则的、随时间不断改写的，不能保持一条平齐直线或恒定宽度。

【速度与声音节奏】
- 速度包络：静止 → 蠕动（几乎看不出） → 突然加速 → 受阻滞速 → 二次推进 → 衰减停积。镜头运动与音效强弱要跟这个节奏走。
- 声音依次为：雨声 → 细碎开裂 → 低频轰鸣 → 阻滞摩擦与块石碰撞 → 停积后零星的碎石余响与雨后环境声。

【禁止】
- 匀速直线平移、边界平直、宽度恒定、整块同时变色、无厚度的贴地滑动。
- 整片滑体同时启动、同时停止。
- 用一个连续光滑的褐色面代表全部滑体。

【验收】
- 把 4 / 8 / 12 / 16 s 四帧的滑体前缘位置连起来，轨迹应是明显的折线或曲线，不能是直线。
- 全程前缘最大宽度与最小宽度之比大于 2。
- 能明确指出至少 1 次转向、1 次分叉后汇流、1 次停滞再启动、1 次扇形扩散。
- 20 s 的堆积形态与 12 s 的流动形态应明显不同（厚度、宽度、表面结构均可辨）。
```

## P4｜镜头、字幕与声音配合

```text
任务：在不改变 24 秒片长、七段分镜结构、六段中文旁白时间点、片尾结果卡与致谢的前提下，调整镜头与字幕，让前面三项改造能被观众读出来。

- 0–3.5 s 不要用俯视镜头「指认」某块区域：改为缓慢平移或略低角度扫过整片山坡，雨、雾、湿润变化是主角；字幕仍只给「降雨入渗 + 累计分钟数」。
- 失稳瞬间：一次极短的镜头轻震 + 短促推近，让观众自己发现裂缝；不要用箭头、圈选、高亮或字幕提示位置。
- 中段保留一个低角度侧视，但把它对准沟谷转弯处，让「地形逼着滑体转向」可被看见；再给一个约 2 秒的俯视或剖面式镜头，让分叉与汇流可读。
- 分叉段镜头不要切得太碎，否则观众来不及理解两股物质的关系；至少留 1.5 秒连续观察时间。
- 字幕每段仍只保留 1 个标签 + 1 个数字；可在过程段使用「张裂」「受阻」「转向」「扩散」这类过程词，但不叠加参数表。
- 六段旁白时间点不变；把「安全系数降到一以下，坡体失稳」改为更贴合「突然发生」的语气，其余文案与语速保持。
- 片尾结果卡的峰值速度、推进距离、源区滑失、坡脚堆积、受损建筑、响应树木等数字与显示假设一律不变；如要体现新增过程，可另加一行不超过 12 字的过程标签。

【验收】24 s / 720 帧 / 30 fps 不变；单行字幕不变；六段旁白时间点不变；片尾数字与致谢不变；观众在 0–3.5 s 内没有被引导去看某一块特定区域。
```
