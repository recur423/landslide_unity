# 流域版 24 秒分镜与验收

帧号从 0 开始，按 30 fps 计算。分镜表给出镜头与预期画面，逐秒区间也用作查找运动事件的窗口。实际画面见文末验收记录。

## 七段分镜

| 帧号 | 时间 | 镜头与画面 | 单行字幕 |
|---|---|---|---|
| 0–104 | 0–3.5 s | 阴雨全坡横移，以雨、坡面湿润和沟底漫水为主。 | 降雨入渗 + 累计分钟数 |
| 105–209 | 3.5–7 s | 一次轻震后缓推，先读到源区的小裂口，再看到草皮错动和滑体进入收窄沟道。 | 滑体启动 + 当前速度 |
| 210–359 | 7–12 s | 俯视连续跟拍沟道岩嘴。两股绕行、短暂滞留、再推进和汇合都留在同一景别内。 | 受损建筑 + 当前受损数 |
| 360–449 | 12–15 s | 降低视角，同时容纳弯沟、两侧错动和村落冲击。 | 转向冲击 + 当前受损数 |
| 450–539 | 15–18 s | 从沟弯低视角升到坡脚斜俯视，前缘与两侧扩散范围同时入画，树木和房屋提供尺度。 | 树木响应 + 当前响应数 |
| 540–599 | 18–20 s | 拉宽观察扇形堆积，近处块石先停，细粒薄舌继续推进。 | 坡脚堆积 + 当前体积 |
| 600–719 | 20–24 s | 前 1 秒读停积形态，后 3 秒在虚化全景上显示原计算结果、显示假设和致谢。 | 前缘推进 + 距离，21 s 起进入结果卡 |

## 逐秒可见变化

| 时间 | 帧号 | 画面与声音 |
|---|---|---|
| 0–1 s | 0–29 | 镜头从斜侧方扫过完整草坡，用村落和谷线建立尺度。稀疏雨声下，0.30 s 旁白“连续降雨，坡体逐渐吸水。” |
| 1–2 s | 30–59 | 雨丝变密，草坡随降雨整体压暗，沟底和凹地先出现反光。 |
| 2–3 s | 60–89 | 主沟与支沟湿润边界逐步清楚，谷地薄雾衬出起伏。画面仍是一整片覆盖连续的坡面。 |
| 3–4 s | 90–119 | 第 105 帧起轻震和推近，第 112 帧可见几道细裂，第 115 帧在裂缝后端见到局部湿土。3.65 s 接入旁白“安全系数跌破一，坡面突然裂开。” |
| 4–5 s | 120–149 | 湿土沿少数裂缝边露出并逐步连通，局部草皮下错。零散碎石声渐变为低频摩擦声。 |
| 5–6 s | 150–179 | 块体陆续启动，后缘留下台阶，前部滑入低处。土体轰鸣随之增强。 |
| 6–7 s | 180–209 | 前缘随沟道收窄并增厚，草坡和擦痕仍从两侧可辨。 |
| 7–8 s | 210–239 | 俯视顺着主沟看向岩嘴，两股运动方向开始分开。7.45 s 旁白“滑体加速下行，冲向下方村落。” |
| 8–9 s | 240–269 | 主沟一股继续前进，侧股先滞留在岩嘴上端，8.57 s 起下游出现新的窄褐带。岩嘴附近传来短摩擦和碎石撞击。 |
| 9–10 s | 270–299 | 两股土舌到达岩嘴两侧，较薄的一股和主沟土舌在下游并入同一片湿土。低频短促回升。 |
| 10–11 s | 300–329 | 镜头保留同一岩嘴与两股尾迹，给观众读出上游分开和下游汇合的空间关系。 |
| 11–12 s | 330–359 | 弯沟入口和迎坡房屋同时入画，滑体贴住沟底改变方向。 |
| 12–13 s | 360–389 | 镜头降到斜侧方，滑体弯转与靠近房屋的擦碰可见。12.15 s 旁白“滑体撞击房屋，墙体与屋顶破坏。” |
| 13–14 s | 390–419 | 沟弯内侧出现挤压堆高和块间错台，外侧可见薄层擦越。房屋破坏仍由原回放事件发声。 |
| 14–15 s | 420–449 | 弯道下口和坡脚同时可见，前缘开始由沟内窄舌走向开阔地。 |
| 15–16 s | 450–479 | 从沟弯低视角缓升，重新把坡脚和村落纳入一幅画面。15.55 s 旁白“土体卷起树木，碎屑继续运移。” |
| 16–17 s | 480–509 | 多个短舌向扇面分开，粗颗粒落在近侧，细粒继续向前铺展。 |
| 17–18 s | 510–539 | 侧向展宽与坡脚减速同时可见，土石轰鸣开始收弱。 |
| 18–19 s | 540–569 | 镜头拉开，堆积外缘与内部垄岗入画，偶发碎石碰撞。 |
| 19–20 s | 570–599 | 扇缘不同部位陆续停下，留下不规则舌尖、凹坑和块石。余响分散、低频继续减弱。 |
| 20–21 s | 600–629 | 返回全坡，展示沟道和最终堆积的对应位置。20.85 s 旁白“六栋房屋受损，前缘推进二百一十七米。” |
| 21–22 s | 630–659 | 背景虚化并淡入结果卡，旁白延续，环境底声保持。 |
| 22–23 s | 660–689 | 保持结果数据、房屋分级和显示假设可读。 |
| 23–24 s | 690–719 | 保持结果与素材致谢可读，雨后底声淡出。 |

## 逐帧验收

| 项目 | 取证帧或范围 | 合格 | 未达标 |
|---|---|---|---|
| 1．首帧盲测 | 0、60 | 给三位首次观看者只看这两张图，三人均无法用画面线索圈出未来滑体。记录每人的回答。 | 有人根据土色、植被空缺、锐边、描线或构图圈对。没有三份真实回答时记为待验。 |
| 2．从裂到滑 | 0、60、104、105、120、150、240 | 第 0 至 104 帧无连续裸土斑标出源区。第 105 帧起先见局部裂纹，再见裂缝旁不规则湿土。裸露面积从第 120 帧走向第 240 帧逐步增大。 | 失稳前有可读的裸土轮廓，或湿土同期整块变色。 |
| 3．流域地貌 | 0、60、240、390、480、600 | 眼睛能沿地形指出弯曲主沟与至少一条弯曲支沟、横向岩脊、上游浅凹和坡脚扇。低视角能辨认地势起伏。 | 地形仍读成单一斜面，沟脊主要靠颜色表达，或任何一项指定地貌不可指认。 |
| 4．前缘曲线及展宽 | 120、240、360、480，并在整个运移段取样 | 从同一世界坐标或固定俯视机位标出每个前缘代表点，连线有明显方向变化。以统一横向测量口径得到最大宽度与最小有效前缘宽度之比大于 2。 | 用不同移动机位的屏幕坐标直接连线，固定坐标下连线近直，或比值不超过 2。 |
| 5．四项运动事件 | 约 7–10.5 s 的绕行画面、11–15 s 的弯转画面、15–20 s 的坡脚画面 | 逐项记下转向、分叉后汇合、受阻后再推进和扇形扩散的实际帧号或区间。同一机位有至少连续 45 帧可观察分叉关系。 | 任何一项找不到画面证据，或只靠字幕、旁白、音效提示。 |
| 6．停积形态 | 360 与 600 | 第 600 帧可辨宽扇、较薄的边缘和内部垄岗、凹坑或块石堆，与第 360 帧的较厚运动前缘有区别。 | 只见同质平滑色带，首末形态基本相同，或完全依赖机位差制造差异。 |
| 7．土体连续性 | 0–629，重点 105–150、210–359、450–600 | 新露土体沿裂缝、剥落面或正在推进的前缘出现。块体和不同舌尖有先后，前缘持续变化。 | 有孤立土块凭空显形、厚片整片腾空、火光爆炸、整片齐头运动或整块瞬变。 |
| 8．节目规格 | 全片，20.85 s 与 630–719 | 720 帧 / 24 s / 30 fps / 1280×720。字幕用一条标签搭配一个数字。六段旁白从 0.30、3.65、7.45、12.15、15.55、20.85 s 起播。结果卡数字、显示假设与致谢逐项对原版。 | 时长、格式、旁白节点、单行结构或任何片尾参数和致谢有改动。 |
| 9．数值边界 | 720 条元数据和原始字节 | 原始数据 SHA-256 与路线 A 一致，逐帧时钟、FS、雨时、速度和前缘推进与基线相等，并复核终局体积、建筑和树木数量。 | 任一物理数值或数据校验值出现差异。 |
| 10．过程说明 | 工程表现说明与结果卡 | 工程说明清楚划分显示地形、分流汇流和块体动画的教学用途，结果卡注明数字来自原数值场。 | 把额外地形与运动画面当作求解器已计算出的新机理。 |

第 1、3、4、5 项任一未通过或待验时，保留该项状态。三人盲测采用真实首次观看者。制作组的画面检查不能代替盲测。
