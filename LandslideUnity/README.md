# Unity 降雨滑坡交互演示

使用 Unity **2022.3.62f3c1**、Built-in 内置渲染管线，读取 Python 数值仿真数据回放。当前流域版从完整雨坡过渡到局部开裂，在同一数值回放上呈现弯曲沟谷、岩嘴分流和坡脚扇形停积。地表使用三套 Poly Haven 实拍 2K 贴图（CC0），树、房屋、天空和环境音效由工程生成。

[流域版成片](Documentation/unity_watershed_demo_30fps.mp4) · [逐秒分镜与验收](Documentation/WATERSHED_STORYBOARD.md) · [路线 A 成片](Documentation/unity_route_a_demo_30fps.mp4) · [素材来源](Documentation/ASSET_SOURCES.md)

## 打开与操作

在 Unity Hub 添加本目录，打开 `Assets/Scenes/LandslideDemo.unity` 后按 **Play**。场景在运行时生成。也可运行同级 `LandslideUnityPlayer/LandslideDemo.exe`；必须保留整个 Player 目录。

| 操作 | 功能 |
|---|---|
| 右键拖动 / 滚轮 | 自由旋转 / 缩放 |
| 空格 / R | 暂停或播放 / 从头重播 |
| Tab / 详细数据按钮 | 默认简洁 HUD；展开或收起 FS 曲线、房屋参数和显示说明 |
| 时间轴 | 前后定位，房屋、树木和碎片恢复对应状态 |
| 全景 / 滑体特写 / 房屋特写 | 切换山体、滑体前缘、村落视角 |
| 点击房屋 / 详细模式下点击 H1–H6 编号 | 展开对应房屋的厚度、速度、接触阈值、需求比和损伤阶段 |
| 破碎 / 扬尘 | 关闭额外碎土和尘土，保留主要房屋损伤状态 |
| 树木 / 岩石 | 切换装饰和重点树木显示 |
| 速度 | 调整交互回放速度 |

## 本次优化

- **天空与地形边界：** 数值网格外补五圈下折裙边及周边山地，加入分层云天空、线性雾与柔和方向光，避免山坡像悬空切片。周边地貌仅为布景，不参与流场采样与统计。
- **地表质感：** 草、湿土和岩石使用 Poly Haven 2K 实拍 PBR 贴图，按坡度、高度与裸露区域做三平面混合；缺失资源时自动采用原 256×256 程序贴图。42 m 尺度色斑和远景细节淡出减弱重复纹，地表雨中渐暗。滑体使用湿润褐土、沿流向拉伸的裂隙和边缘渐隐；视觉湿润度不替代入渗求解。
- **路线 A 分块与滑面：** 仅用原厚度与速度场构造世界坐标 Voronoi 分块；正向速度梯度张缝、负向梯度闭缝上拱、侧向剪切错动。块缝和倾斜边墙显示表土、风化层、岩色层；四级后缘台阶依次显露。显示地形新增 fBm、浅冲沟和岩脊，`Bed` 原始值不变。这些三维断裂与陡坎属于示意表现，不代表求解器算出了旋转滑面。
- **树木与房屋：** 树冠有四种确定性的高矮宽窄轮廓及随机色调；叶片透明裁切并随回放时钟轻微摆动。树皮、木构、抹灰墙、瓦片、窗格与基础使用共享纹理；房屋底座缩为贴地薄基座。
- **光照与后期：** 保留 Built-in，新增 ACES 近似色调映射、轻 Bloom、色彩调整、暗角、轻量深度/法线接触遮蔽与天空反射探针。尚未迁移 URP，没有使用 Volume 或完整 SSAO。
- **画面与信息：** 交互默认简洁 HUD，Tab 查看完整数据；视频按雨、失稳、村落、房屋近景、低侧视、坡脚、全景七段组织，每段只显示一个阶段标签和一个核心数字。镜头在 0.8 秒内缓动；片尾在虚化场景上集中列出结果与假设。
- **音轨：** 雨声、滑动低频、碎石及冲击声由程序合成，并随逐帧速度和损伤阶段同步；六段中文旁白由本机 Microsoft Huihui 系统语音生成，均不是现场录音。
- **滑体体积：** 厚度显示 5×，叠加不超过 ±16% 的表面起伏；前缘、侧缘具有厚度立面。源区保留马蹄形后缘陡坎与裂缝，滑失后露出较低的滑面。坡脚堆积来自原始逐时厚度场。
- **房屋因果链：** 迎滑侧墙先受损，随后主体倾斜、屋顶失撑、碎片拖移。墙体与屋顶的释放时间分开，明显过程持续约 4–5 秒；基础逐步掩埋，部分房屋保留残墙和半片屋顶。
- **损伤分级：** 终局为 2 栋轻损、2 栋局部倒塌、2 栋整体倒塌。
- **树木：** 145 棵静态背景树之外，22 棵重点树按流场响应，11 棵拔起、11 棵折断。先明显倾倒，再运移和沿树干方向翻滚，保留树桩与根团，坡脚具有局部掩埋。
- **依据：** 详细模式的安全系数曲线读取实际降雨入渗计算结果，标出累计降雨第 89 分钟失稳。编号房屋面板显示实际局地厚度、速度与阈值。
- **指标：** 区分“累计降雨时间”“失稳后时间”“当前最大速度”“全过程峰值”；结尾显示前缘推进、源区滑失、坡脚堆积及受损数量。
- **视频：** `Documentation/unity_watershed_demo_30fps.mp4` 为 24 秒、1280×720、30 fps，包含中文旁白和 AAC 双声道音轨。前 21 秒使用单行字幕，最后 3 秒呈现计算结果、显示假设和贴图来源。

## 数据与显示增强

`Assets/StreamingAssets/landslide.bytes` 保存 420×70 网格、91 个时刻（0.5 s 间隔），包含高程、厚度、x/z 速度、降雨、安全系数、质量和能量，单位为 m、s、kg、J。交互回放前 8 秒压缩显示 89 分钟降雨，随后回放 45 秒运移。

安全系数、速度、体积与阈值使用**原始计算数值**。显示表面采用 `实际厚度 × 5 × 起伏系数`，起伏系数为 0.84–1.16；树木、碎片的显示高度遵守同一约定。视觉增强后的几何体积不参与仿真质量或能量统计。

终局原始数据：前缘推进约 217.0 m，源区（x=55–125 m）滑失约 3034 m³，坡脚（x≥250 m）堆积约 1447 m³。全过程场内最大速度约 18.2 m/s。场地与材料参数为演示设定，完整假设见同级 `landslide_demo/README.md`。

## 房屋与树木触发

房屋在中心及上游边缘取样，接触条件是 `h>0.08 m` 且 `|v|>1.2 m/s`。累积最大需求 `I=max(h|v|²)` 与各房屋演示能力常数 `C={90,95,80,100,60,45}` 比较；`I/C≥0.65` 对应局部倒塌，`I/C≥1.35` 对应整体倒塌。阶段时间进一步限制释放速度，避免刚接触就瞬间完全破碎。能力常数与倒塌为表现设定，不构成结构验算，也不反馈修改坡面流场。

树木按局地厚度、速度触发，先倾斜超过 60°，约 0.75 s 后输运。断裂、根团、跳动、掩埋和扬尘为可定位回放的表现层。

## 性能与构建

[性能实测](Documentation/PERFORMANCE.md) 分列 **2026-11-17 路线 A** 与 2026-11-06 历史基线。路线 A 在 1280×720 离屏相机、失稳后 10–24 s 轨迹上采样 480 帧，脚本更新中位 **15.728 ms**，Player 帧间隔中位 **29.344 ms**。计时不含 PNG/视频编码与交互 HUD；测量覆盖分块、裂缝、贴图、后期及房屋、树木响应，但不能保证所有硬件和交互窗口的帧率。视频 30 fps 是导出规格。

滑体仅更新活动顶点并缓存拓扑；背景树不再逐帧移动，暂停时跳过状态重复更新。276 个大墙板、屋顶及山墙保留 BoxCollider 和运动学 Rigidbody；细片无碰撞体，运动学大块不求解碎屑互撞，稳定碎片固定并休眠。仅少数速度超过 6 m/s 的屋顶角片使用 Continuous Speculative，其余使用 Discrete。大碎片依然按确定性路径回放。

菜单 **Landslide Demo → Build Windows Player** 可重建运行版；本机 Unity 路径为 `E:\graduate\unity\2022.3.62f3c1\Editor\Unity.exe`。构建、自测、关键帧验画与完整视频导出命令见 [PRESENTATION.md](Documentation/PRESENTATION.md)。仅修改表现层时无需重跑仿真；修改降雨或材料参数后，重新运行同级 Python 仿真与 `export_unity.py`。核心组件：`SimulationData`、`LandslideSurface`、`TreeResponse`、`HouseDestruction`、`LandslideDebris`、`SceneController`、`PerformanceProbe`、`PresentationEnvironment`、`PresentationPostProcess`、`SurfaceTextureSet`、`SceneryTextures`。
